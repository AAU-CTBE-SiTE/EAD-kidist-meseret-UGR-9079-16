# Student CRUD API

This is a simple Student CRUD API built using Spring Boot.

## Technologies
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Features
- Create a student
- Get all students
- Get a student by ID
- Update student information
- Delete a student

## Run the Project
Run the `StudentCrudApplication.java` file in IntelliJ IDEA.

## API URL
`http://localhost:8080/api/students`
