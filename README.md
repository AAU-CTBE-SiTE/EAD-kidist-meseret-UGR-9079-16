# Spring Framework Lab 4: IoC and Bean Management

## Description
This lab demonstrates Spring Framework's Inversion of Control (IoC) container and Dependency Injection (DI) using XML configuration.

## Technologies Used
- Java 17
- Maven
- Spring Framework
- Lombok
- IntelliJ IDEA

## Topics Covered
- Spring IoC container and beans
- Setter-based injection
- Constructor-based injection
- Object dependency injection
- Collection dependency injection
- Singleton and prototype bean scopes

## How to Run
1. Open the project in IntelliJ IDEA.
2. Allow Maven to download the dependencies.
3. Open `App.java`.
4. Run the `main` method.

## Configuration
Spring bean definitions are configured in `src/main/resources/beansConfig.xml`.
